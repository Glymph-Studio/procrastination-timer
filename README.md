# Procrastination Timer - Glymph Studio

> How long have you been avoiding it?

Live: `procrastination.glymph.vercel.app`
Built by [@Yash-Tripath1](https://github.com/Yash-Tripath1) for Glymph Studio

### Features
- Landing -> Timer -> Victory flow
- Counts up 00:00:00, shame messages escalate over time
- Victory with random roast + total wasted
- Past crimes history (last 5) with total/avg/longest
- Screenshot card via Canvas API (no html2canvas dep)
- Dark / Light theme toggle
- Tab title live, visibility shame detection, resume on reload
- Mobile-first, slick animations

Built by Glymph Studio - glymph.vercel.app
